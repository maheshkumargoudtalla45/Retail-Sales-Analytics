# Retail Sales & Business Performance Analytics

## Project Overview
This project analyzes retail sales data to understand revenue trends, store performance, and product-level sales patterns.

## Business Objectives
- Identify high-performing stores and product categories
- Track revenue and order trends
- Calculate business KPIs
- Present findings through interactive dashboards

## Technologies
SQL, Python, Pandas, Power BI, Excel

## Project Workflow
1. Prepare and validate sample retail data
2. Analyze transactions using SQL
3. Clean and transform data using Python
4. Develop Power BI reports
5. Document findings and recommendations
